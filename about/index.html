About

Robert Kiptoo

I'm a software engineer with a Diploma (Hons) in Software Engineering, currently on the FlyRank internship's backend track. I build the part of a product that has to keep working when users send bad input, traffic spikes or a dependency goes down.

I don't ask anyone to take "it works" on trust. Every system I ship comes with the tests, probes and transcripts that show it working, and says honestly where it doesn't yet.

How I work

  • Tests first. The requirement becomes a test before it becomes code.
  • An evidence file for every requirement. One pasted proof per checkbox, from a real run.
  • A weekly demo. You see working software every week, not a status update.
  • Degrade, don't crash. When a dependency fails, the response gets smaller, not broken.

Tools

Python, FastAPI, PostgreSQL, SQLAlchemy, Docker, pytest, and LLM APIs (Ollama and OpenRouter).
